# 🌊 인천 물때달력 2026 — 아이폰 앱 설치 가이드

## 📱 아이폰에서 앱으로 설치하는 방법

### 1단계: GitHub Pages 무료 호스팅 업로드
1. https://github.com 접속 → 무료 계정 만들기 (이미 있으면 로그인)
2. 우측 상단 **+** → **New repository** 클릭
3. Repository name: `tide-app` 입력
4. **Public** 선택 (중요!)
5. **Create repository** 클릭
6. **uploading an existing file** 클릭
7. 이 폴더 안의 파일 전체 선택하여 드래그 업로드
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
   - .nojekyll
8. **Commit changes** 클릭

### 2단계: GitHub Pages 활성화
1. repository 페이지에서 **Settings** 탭 클릭
2. 왼쪽 메뉴 **Pages** 클릭
3. Source: **Deploy from a branch** 선택
4. Branch: **main** / **/ (root)** 선택
5. **Save** 클릭
6. 잠시 후 주소 생성됨: `https://[내아이디].github.io/tide-app/`

### 3단계: 아이폰 홈 화면에 추가 (로그인 불필요!)
1. 아이폰 **Safari**로 위 주소 접속
2. 하단 **공유 버튼** (□↑) 탭
3. **홈 화면에 추가** 탭
4. **추가** 탭
5. 완료! 이후 홈 화면의 🌊 아이콘만 클릭하면 앱 실행
